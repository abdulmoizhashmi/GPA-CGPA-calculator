# Calcura — Calculator & GPA/CGPA

Open `index.html` directly in a modern browser. No build step is required.

## Features
- Basic arithmetic: +, −, ×, ÷, %, clear and backspace
- Keyboard support
- GPA calculator using A 4.0, B+ 3.5, B 3.0, C+ 2.5, C 2.0, F 0.0
- CGPA calculator using Σ(grade points × credits) / Σ(credits)
- Dark-mode toggle, mobile menu, sticky header, loading animation and back-to-top
- Responsive component-based JavaScript
- Lucide icons loaded from the official package CDN
